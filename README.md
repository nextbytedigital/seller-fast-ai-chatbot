# 🚀 Seller Fast AI Chatbot - Full SaaS Platform

An enterprise-grade, AI-powered customer support and sales automation chatbot designed for WordPress and Shopify ecosystems. Developed and maintained by **NextByte Digital**.

## 🌟 Project Overview
This repository contains the core widget integration files for the Seller Fast AI Chatbot. The complete system is a fully automated SaaS platform built to handle 24/7 customer inquiries, recommend products, and drive sales while you sleep.

## 🛠️ System Architecture & Technologies
This platform leverages a powerful, modern tech stack:
* **Frontend & Client Portal:** Built with [Softr](https://www.softr.io/) for seamless user onboarding, dashboard management, and database tracking.
* **Backend Automation:** Powered by [n8n](https://n8n.io/) to handle complex email sequences, CRM updates, and logic routing.
* **Payment Gateway:** Fully integrated with [Stripe](https://stripe.com/) for automated subscription billing and trial management.
* **Core Integrations:** Custom PHP/JS plugins tailored for **WordPress/WooCommerce** and **Shopify**.

## ✨ Key Features
- **Automated 15-Day Trial System:** Automatically tracks user signups and sends targeted email reminders before expiration via n8n.
- **Seamless Subscription Management:** Instant account status updates (Paid/Expired/Free) based on automated Stripe webhook triggers.
- **Smart AI Routing:** Understands customer queries and assists them interactively.
- **Plug-and-Play Widget:** Easy installation via `seller-fast.php` for WP and a lightweight JS snippet for Shopify.
